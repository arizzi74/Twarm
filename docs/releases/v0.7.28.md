# v0.7.28

- Allow up to 120 seconds for Claude Code initialization on slower workers. Startup failures identify initialization errors and state when the prompt was not sent. Cancellation remains responsive, and failed prompts are not automatically replayed.
- Add `/tgrestartworker` in Telegram and the WebUI. Confirmation names the selected session’s worker and warns that all its sessions are affected. Cancel keeps the worker running.
- Restart requests retain their original worker/session target, expire after one minute, and are deduplicated across connection failures and process restarts. The installed service must own the requesting worker process. Linux systemd and macOS launchd supervise the restart independently of the worker.

Validation covers the affected Claude lifecycle, worker command ledger, routing and authentication, browser confirmation and session isolation. Unchanged audio inference checks are excluded from the guarded maintenance release; release packaging and provenance verification remain required.
