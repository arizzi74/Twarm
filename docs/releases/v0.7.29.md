# v0.7.29

Claude Code sessions now support `/mcp` in the WebUI and Telegram through native MCP controls, without submitting model prompts.

- `/mcp` lists server connection states and tool counts; `/mcp verbose` includes scope, server version and tool names.
- `/mcp reconnect [server|all]`, `/mcp enable <server|all>` and `/mcp disable <server|all>` manage the selected session’s connections. Reconnect-all retries failed connections and those needing authentication.
- MCP administration preserves the active coding turn. Requests retain their original session scope and unconfirmed changes are not automatically replayed. Server configuration, headers, environment and raw errors are excluded from returned status.
- Interactive authentication remains available through native Claude Code on the worker host.

Validation covers native controls, lifecycle, session isolation, argument validation, update-safety handling and browser commands. Unchanged audio inference tests are excluded by an exact release-scope guard; packaging, security checks and provenance verification remain required.
