# v0.7.33

Twarm now publishes from [arizzi74/Twarm](https://github.com/arizzi74/Twarm),
including both public websites and the simplified installation commands.

- Bootstrap with the independently authenticated v0.7.32 bridge manager on all
  four supported platforms. Keep the one-line curl installer and noexec fallback.
- Complete `twarm`, `mact` and `codex-telegramgw` aliases during normal updates
  and same-version queued checks, after pending readiness checks succeed.
- Keep Telegram `/tg…` commands, existing service and configuration names,
  project paths, sessions, passkeys, trusted devices and installed-app identity.
- Publish new provenance under Twarm while retaining exact MACT and legacy
  signing identities for historical releases. Compatibility repositories retain
  the frozen v0.7.32 bridge; MACT also preserves v0.7.10 bootstrap-manager files.
- Update release recovery automation to address the renamed canonical repository.

The supplied Twarm icon and wordmark appear throughout the app, admin console,
website and default bot-profile reset. Both public sites use the charcoal and
lime palette. The sites use fictional screenshots and make no gateway requests.

Validation includes signed updater and installer rejection tests, aliases and
rollback/readiness cases, release/recovery guards, relevant HTTP/browser tests,
deterministic icons, responsive websites and cross-platform package verification.
Unchanged audio inference tests are excluded.
