# v0.7.32

MACT becomes **Twarm**, a control hub for Codex and Claude Code.

- Introduce `twarm` as the terminal management command while retaining `mact`
  and `codex-telegramgw` aliases. Telegram `/tg…` commands stay unchanged.
- Apply the supplied Twarm icon, wordmark and lime/charcoal branding across the
  Web UI, admin console, home-screen assets, default bot profile and public sites.
- Add a signed updater bridge that follows the official repository by its fixed
  GitHub identity before and after the move from `arizzi74/MACT` to
  `arizzi74/Twarm`. Preserve exact historical signing policies, safe rollback
  and readiness checks.

Existing service names, configuration, database paths, sessions, project folders,
passkeys, trusted-device sessions and `/tgw/` URLs keep their identifiers.

The repository move is staged after this bridge release is verified and installed.
Old repository names retain minimal compatibility releases and installer/site
forwarding. See [the migration guide](../twarm-migration.md) for recovery commands
for installations that missed the bridge.

Validation covers release-manager and provenance tests with the race detector,
installer authentication, alias collisions/rollback, relevant HTTP and browser
checks, deterministic brand assets, responsive websites and release scope gates.
Unchanged audio inference is not rerun; cross-platform package and native-helper
integrity checks remain required.
